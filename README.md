# Soham Rane — Portfolio

A responsive portfolio for AI/ML engineer Soham Rane. It is built with plain HTML, CSS, and JavaScript and is published with GitHub Pages from the repository root on `main`.

## Run locally

Open `index.html` in a browser or serve the repository root with any static HTTP server. The theme and reduced-motion settings are saved in the browser.

## Site structure

- `index.html` is the focused landing page for headline results, the Ross Warner internship, and three major projects.
- `projects.html` contains structured MVP, USP, feature, and technology details for the major projects, plus a separate collection of smaller builds.
- `achievements.html` keeps courses, job simulations, coding challenges, exams, workshops, internships, and participation certificates off the main page.
- `football.html` presents four football experiences and achievements, also retained in the achievements archive.
- `portfolio.css` provides the dark-first, light/dark responsive design and reduced-motion styles.
- `script.js` handles navigation, appearance settings, and scroll reveals.
- `assets/images/` contains portfolio, project, achievement, and RapidReach dashboard photos.
- `assets/reports/` contains the Indian Sign Language project report.
- `assets/certificates/` contains certificate images and PDFs shown in the achievements archive.
